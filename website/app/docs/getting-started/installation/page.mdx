# Installation

## Install esdev

Install ES-Runtime's **esdev** development binary before creating a project.
Use esdev 0.15 or newer and a package manager such as pnpm.

<Tabs tabs={installTabs} />

Verify the installation before continuing:

```bash
esdev --version
```

See the official [installation guide](https://esrun.opentechf.org/docs/install)
for version pinning, upgrades and custom install locations.

## Create a project

```bash
esdev create my-app
```

Follow the prompts to choose a template, language and package manager.

## Non-interactive usage

Specify your choices with flags for scripts or CI:

```bash
esdev create my-app --template=spa --language=js --package-manager=pnpm
```

Use `--language=ts` for TypeScript and `esdev create --help` for supported options.

Available templates:

| Template | Purpose |
| --- | --- |
| `spa` | A browser app with file-based routing and client rendering. |
| `fullstack` | A browser app with a server entry for APIs, middleware and request rendering. |
| `docs` | An MDX docs/blog site with prerendered HTML, navigation and search. |
| `library` | A source package of reusable components compiled by its consumers. |

Template files are embedded in esdev; package versions are resolved while scaffolding.

<Callout type="warning" title="OTF template migration">
  The installed esdev 0.15 OTF app templates still emit retired CLI scripts and
  omit esdev.json. They need an upstream update and a new esdev binary release.
  Until then, use the native config and entry files from
  [Production Build](/docs/deployment/build) instead of the generated otfw scripts.
  The create-web package is deprecated.
</Callout>
