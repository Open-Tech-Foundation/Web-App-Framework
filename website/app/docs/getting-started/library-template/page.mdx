# Library Template

Component libraries can ship JSX/TSX source from `index.js`. Consumer apps compile
that source with `@opentf/esdev-plugin-web`; the library does not need to bundle a
second copy of the framework.

```bash
esdev create my-lib --template=library --package-manager=pnpm
```

The generated project compiles components for tests and includes a rendering test;
`esdev test --dom` runs it.

## Package entry

```js index.js
export { default as Counter } from "./src/Counter.jsx";
```

Include `index.js` and `src/` in the package's `files` list, and make `@opentf/web`
a peer dependency. Install the runtime, plugin and test helpers for development:

```bash
pnpm add -D @opentf/web @opentf/esdev-plugin-web @opentf/web-test
```

## Sample component

```jsx src/Counter.jsx
export default function Counter(props) {
  let count = $state(props.initial ?? 0);
  return <button type="button" onclick={() => count++}>Count: {count}</button>;
}
```

## Rendering tests

The library's `esdev.json` compiles components for client rendering and turns
route discovery off, since a library has no `app/` folder. The
[Testing Setup](/packages/web-test/setup) module registers cleanup:

```json esdev.json
{
  "plugins": [{
    "module": "@opentf/esdev-plugin-web",
    "options": { "target": "csr", "routes": false }
  }],
  "test": { "setup": ["@opentf/web-test/setup"] }
}
```

```js tests/counter.test.js
import { expect, test } from "runtime:test";
import { render } from "@opentf/web-test";
import { Counter } from "../index.js";

test("updates after a click", async () => {
  const { getByRole } = render(Counter, { initial: 2 });
  const button = getByRole("button", { name: "Count: 2" });
  button.click();
  expect(button.textContent).toBe("Count: 3");
});
```

```bash
esdev test --dom
```

Use `--browser` for full user-event interaction sequences. Publishing source and
publishing a compiled library are different workflows; see esdev's official
[library build guide](https://esrun.opentechf.org/esdev/build/library) if consumers
need precompiled output.
