# Testing

Reliable applications require reliable tests. The official `@opentf/web-test` package
provides a lightweight, "React Testing Library"-style utility for testing framework
components. It integrates with **Bun's test runner** and uses **Happy DOM** for a
high-performance virtual browser environment.

## Quick Setup

1. Install dependencies:

```bash
bun add -d @opentf/web-test
```

2. Add to your `bunfig.toml`:

```toml
[test]
preload = ["@opentf/web-test/setup"]
```

## Writing a test

```js
import { expect, test } from "bun:test";
import { render, userEvent } from "@opentf/web-test";
import MyComponent from "./MyComponent.jsx";

test("increment counter", async () => {
  const { getByText } = render(MyComponent);
  const user = userEvent.setup();
  const btn = getByText("Count: 0");
  await user.click(btn);
  expect(btn.textContent).toBe("Count: 1");
});
```
