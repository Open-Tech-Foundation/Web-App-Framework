# Components

Import these from `@opentf/web-docs` and use them inline in any `.mdx` page.

## Callout

Admonition box. `type` is `note`, `tip`, `info`, `warning`, or `danger`; `title` is
optional and defaults to the type.

```mdx
import { Callout } from "@opentf/web-docs";

<Callout type="warning" title="Heads up">
  APIs may change while OTF Web is in pre-release.
</Callout>
```

<Callout type="note">A neutral note.</Callout>
<Callout type="tip" title="Tip">Pass a bare expression to `$derived(a + b)`.</Callout>
<Callout type="warning" title="Experimental">Pre-release APIs may change.</Callout>
<Callout type="danger" title="Avoid">Don't mutate state outside a signal.</Callout>

## Steps

Numbered walkthrough. Each child heading becomes a numbered step, so it composes with
plain Markdown.

```mdx
import { Steps } from "@opentf/web-docs";

<Steps>
### Install
Run `bun add @opentf/web`.

### Start the dev server
Run `bun run dev`.
</Steps>
```

<Steps>
### Install
Run `bun add @opentf/web`.

### Start the dev server
Run `bun run dev` and open the printed URL.
</Steps>

## Tabs

Switchable panels — handy for package-manager variants (npm / pnpm / bun) or any
alternative content. Pass `tabs` as an array of `{ label, content }`. `content` is
rendered as-is: a string is plain text, a node is the node. For a code panel with a
copy button, pass a `CodeBlock`.

```jsx
import { Tabs, CodeBlock } from "@opentf/web-docs";

<Tabs tabs={[
  { label: "bun", content: <CodeBlock code="bun add @opentf/web" /> },
  { label: "npm", content: <CodeBlock code="npm i @opentf/web" /> },
]} />
```

<Tabs tabs={demoTabs} />

## CodeBlock

A standalone code block — the same header-and-copy-button chrome as a Markdown fence,
but built from a string instead of build-time highlighting. Reach for it when the code
doesn't come from a fence: inside `Tabs`, or anywhere you have the source as a JS
value. Props: `code` (the source, required), and optional `lang` (a language chip) and
`name` (a filename shown in the header).

```jsx
import { CodeBlock } from "@opentf/web-docs";

<CodeBlock lang="bash" name="terminal" code="bun add @opentf/web" />
```

Rendered:

<CodeBlock lang="bash" name="terminal" code="bun add @opentf/web" />

<Callout type="info" title="Fenced code blocks get copy buttons for free">
  A plain Markdown fence in a docs page is highlighted at build time and decorated
  with a copy button at runtime — no component needed. Use `CodeBlock` only when the
  code isn't a fence (e.g. a tab panel).
</Callout>
