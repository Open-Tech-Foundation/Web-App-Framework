# Components

Import these from `@opentf/web-docs` and use them inline in any `.mdx` page.

## Callout

Admonition box. `type` is `note`, `tip`, `info`, `warning`, or `danger`; `title` is
optional and defaults to the type.

```mdx
import { Callout } from "@opentf/web-docs";

<Callout type="warning" title="Heads up">
  APIs may change while OTF Web is in pre-release.
</Callout>
```

<Callout type="note">A neutral note.</Callout>
<Callout type="tip" title="Tip">Pass a bare expression to `$derived(a + b)`.</Callout>
<Callout type="warning" title="Experimental">Pre-release APIs may change.</Callout>
<Callout type="danger" title="Avoid">Don't mutate state outside a signal.</Callout>

## Steps

Numbered walkthrough. Each child heading becomes a numbered step, so it composes with
plain Markdown.

```mdx
import { Steps } from "@opentf/web-docs";

<Steps>
### Install
Run `bun add @opentf/web`.

### Start the dev server
Run `bun run dev`.
</Steps>
```

<Steps>
### Install
Run `bun add @opentf/web`.

### Start the dev server
Run `bun run dev` and open the printed URL.
</Steps>

## Tabs

Switchable panels. Pass `tabs` as an array of `{ label, content }`. A string
`content` is rendered as a code line; pass a node for richer content.

```jsx
import { Tabs } from "@opentf/web-docs";

<Tabs tabs={[
  { label: "bun", content: "bun add @opentf/web" },
  { label: "npm", content: "npm i @opentf/web" },
]} />
```

Rendered:

<Tabs tabs={demoTabs} />

## CodeGroup

Tabs specialized for grouping code (e.g. package-manager variants). Pass `items` as
`{ label, content }`; a string `content` is wrapped in a code block.

```jsx
import { CodeGroup } from "@opentf/web-docs";

<CodeGroup items={[
  { label: "bun", content: "bun create @opentf/web app" },
  { label: "pnpm", content: "pnpm create @opentf/web app" },
]} />
```

Rendered:

<CodeGroup items={demoGroup} />

<Callout type="info" title="Code blocks get copy buttons for free">
  Any fenced code block in a docs page is highlighted at build time and decorated
  with a copy button at runtime — no component needed.
</Callout>
