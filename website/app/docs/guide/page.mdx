# Writing Docs in MDX

This entire page is an **`.mdx`** file. Markdown becomes static HTML at build time,
embedded components stay fully interactive, and fenced code is syntax-highlighted by
the compiler — no client-side highlighter needed.

<Note />

## Markdown, the usual way

You get the things you expect: **bold**, *italic*, `inline code`, [links](/docs),
lists, and tables.

- Compiles to native DOM operations
- Zero virtual DOM
- Fine-grained signal reactivity

| Feature        | Supported |
| -------------- | --------- |
| Headings + ids | yes       |
| GFM tables     | yes       |
| Frontmatter    | yes       |

## Fenced code is highlighted at build time

```js
// Reactive state with the $state macro — no .value needed.
let count = $state(0);
const doubled = $derived(() => count * 2);

$effect(() => {
  console.log(`count is ${count}, doubled is ${doubled}`);
});
```

## Embedded components stay interactive

Drop any framework component straight into the prose and it hydrates as a real
custom element:

<Counter />

That counter is the same `<Counter/>` used elsewhere in the site — imported at the
top of this MDX file.
