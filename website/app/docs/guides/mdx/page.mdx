# MDX & Docs

`.mdx` files are routes too — Markdown with JSX components. `@opentf/web-docs` provides
a themed documentation shell (navbar, sidebar, TOC, callouts) on top of them.

## Frontmatter

Each page starts with frontmatter. `title` feeds the sidebar and breadcrumbs:

```mdx
---
title: Reactivity
description: Signal-based state.
---

# Reactivity
```

## Components in MDX

Import and use components inline — for example a callout:

```mdx
import { Callout } from "@opentf/web-docs";

<Callout type="tip" title="Heads up">Note the type prop.</Callout>
```

<Callout type="tip" title="Callout types">
  `note`, `tip`, `info`, `warning`, and `danger` each get their own accent.
</Callout>

## Sidebar

The sidebar is generated from the folder tree. A folder's `_meta.js` sets the order
and labels of its children; a folder without a page becomes a group subheading.

```js
// app/docs/_meta.js
export default {
  index: "Introduction",
  "getting-started": "Getting Started",
  "core-concepts": "Core Concepts",
};
```

## Configuration

Site-wide options live in `otfw.config.js` — brand, version, GitHub link, and the
top-level nav (which supports per-link icons):

```js
import { defineDocsConfig } from "@opentf/web-docs/config";

export default defineDocsConfig({
  docs: {
    title: "OTF Web",
    version: "v0.4.0",
    github: "https://github.com/Open-Tech-Foundation/Web-App-Framework",
    nav: [{ label: "Docs", href: "/docs" }],
  },
});
```
