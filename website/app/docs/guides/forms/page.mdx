# Forms

`@opentf/web-form` is a reactive, path-based form library. `createForm` returns a form
object you bind to inputs.

## Basic usage

```jsx
import { createForm } from "@opentf/web-form";

export function LoginForm() {
  const form = createForm({
    defaults: { email: "", password: "" },
  });

  const onSubmit = (values) => console.log(values);

  return (
    <form onsubmit={form.handleSubmit(onSubmit)}>
      <input {...form.register("email")} />
      <input {...form.register("password")} type="password" />
      <button>Sign in</button>
    </form>
  );
}
```

`form.register(path)` returns the props that bind an input to that field. Paths are
dotted, so nested state works: `form.register("profile.firstName")`.

## Validation

Pass a validator — `zodResolver` adapts a Zod schema:

```jsx
import { zodResolver } from "@opentf/web-form";

const form = createForm({
  defaults: { email: "" },
  validator: zodResolver(schema),
});

{form.errors.email && <span>{form.errors.email}</span>}
```

## Reactive state

The form exposes reactive flags you can read in bindings:

| Field | Meaning |
| --- | --- |
| `form.isValid` | All fields pass validation. |
| `form.isTouched` | A field has been interacted with. |
| `form.isChanged` | Values differ from the defaults. |
| `form.isSubmitting` | An async submit is in flight. |
