# Reactivity

## The $state Macro

State management in OTF Web is powered by signals, but you never have to deal with
`.value`. The compiler automatically tracks variables declared with `$state()` and
injects reactivity seamlessly.

```js
let count = $state(0);

// Just reassign or mutate directly
count++;
count = 10;
```

## The $derived Macro

Use `$derived` to create computed values that automatically update whenever their
dependencies change. These are cached and only re-evaluate when necessary.

```js
let count = $state(2);
const doubled = $derived(() => count * 2);
// doubled is 4, automatically becomes 6 if count changes to 3
```

## The $effect Macro

To run side effects when state changes (like fetching data or logging), use
`$effect`. It automatically tracks which states you read inside the function.

```js
$effect(() => {
  console.log(`The count is now ${count}`);
});
```
