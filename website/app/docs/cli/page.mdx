# CLI

OTF Web projects use **esdev** with `@opentf/esdev-plugin-web`. The plugin compiles
JSX/TSX/MDX and discovers routes; esdev bundles JavaScript, processes CSS, runs tests
and manages the development loop. The historical `otfw` executable is retired.

| Command | Purpose |
| --- | --- |
| `esdev start` | Build and watch the targets configured in esdev.json. |
| `esdev build --minify` | Build release output. |
| `esdev preview` | Serve the existing static release output. |
| `esdev test --config=esdev.test.json --dom` | Run tests in the native DOM realm. |
| `esdev test --config=esdev.test.json --browser` | Run tests in a real browser with its matching driver. |
| `esdev typecheck` | Run the project's TypeScript checker. |

In this repository, `tsr dev`, `tsr site`, `tsr site-build`, `tsr test` and
`tsr test-e2e` are the shared entry points for those operations.

## Scaffolding

```bash
esdev create my-app --template=spa --package-manager=pnpm
```

OTF templates are `spa`, `fullstack`, `docs` and `library`. They support JavaScript
or TypeScript. Use `esdev create --help` for options.

<Callout type="warning" title="Template migration">
  The installed esdev 0.14 OTF app templates still generate retired otfw scripts and
  omit esdev.json. They need an upstream template update and a new esdev release.
  Do not assume that changing the plugin updates an installed binary's templates.
  The deprecated create-web scaffolder is retained only for compatibility.
</Callout>

## Project configuration

Configure plugins and build targets in `esdev.json`. A browser app needs an HTML
entry whose module script imports `@otfw/routes` and calls `mountApp`.
SSG adds a prerender target with `then: run`; a fullstack app supplies a server entry.
See [Production Build](/docs/deployment/build) and [Server](/docs/deployment/server).

Development uses esdev's rebuild/reload behavior. The old `/__hmr` and `/__route`
contracts belong to the retired CLI; refer to the official
[development loop](https://esrun.opentechf.org/esdev/start) for current behavior.
